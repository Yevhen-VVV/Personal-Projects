# Domain 4: Communication and Network Security (13% of the exam)

## D4-001 | 4.1 | 1
Q: At which layer of the OSI model do routers forward packets based on logical (IP) addresses?
A)* Network (Layer 3)
= Correct. The network layer handles logical addressing and routing between networks.
B) Data link (Layer 2)
= The data link layer uses MAC addresses to move frames within one network segment.
C) Transport (Layer 4)
= The transport layer provides end-to-end delivery with ports, as in TCP and UDP.
D) Session (Layer 5)
= The session layer manages dialogues between applications.
>> OSI: 7 Application, 6 Presentation, 5 Session, 4 Transport, 3 Network, 2 Data link, 1 Physical.

## D4-002 | 4.1 | 1
Q: What is the unit of data called at the transport layer when TCP is used?
A)* Segment
= Correct. TCP data units are segments; UDP's are usually called datagrams.
B) Frame
= Frames belong to the data link layer.
C) Packet
= Packets belong to the network layer.
D) Bit stream
= Bits are the physical layer's unit.
>> Encapsulation: data (layers 5–7) → segment (4) → packet (3) → frame (2) → bits (1).

## D4-003 | 4.1 | 2
Q: An attacker sends thousands of TCP SYN packets with spoofed source addresses and never completes the handshakes. Which control mitigates this attack on the server MOST directly?
A)* SYN cookies
= Correct. With SYN cookies the server keeps no state for half-open connections, so the backlog cannot be exhausted.
B) A longer TCP keep-alive interval
= Keep-alives apply to established connections, not half-open ones.
C) Disabling ICMP on the server
= Blocking ICMP stops ping-based floods, not a flood of half-open TCP connections.
D) Increasing the TCP window size
= The window size controls data flow on established connections.
>> SYN flood: exhausts the half-open connection backlog. Counter with SYN cookies, rate limiting and upstream filtering.

## D4-004 | 4.1 | 1

B)* SYN-ACK

## D4-005 | 4.1 | 2

## D4-006 | 4.1 | 2
Q: Several DNS servers around the world share one IP address, and each client reaches the nearest of them. Which addressing method is this?
A)* Anycast
= Correct. Anycast routes traffic to the nearest node advertising the address, which improves performance and resilience, including against DDoS.
B) Multicast
= Multicast delivers one stream to every member of a group.
C) Broadcast
= Broadcast reaches every host on a local network.
D) Network address translation
= NAT rewrites addresses at a boundary; it does not choose the nearest server.
>> Anycast: one address, many locations, nearest one answers. Used by DNS root servers and CDNs.

## D4-007 | 4.1 | 2
Q: A security team finds that workstations are using an IPv6-over-IPv4 tunneling feature that the perimeter firewall does not inspect. What is the main risk?
A) It exposes internal IPv4 addresses to the internet
= The tunnel wraps IPv6 inside IPv4; the danger is not address exposure but traffic the firewall never inspects.
B)* It can bypass IPv4-only security controls
= Correct. Traffic can bypass controls that only inspect IPv4: tunneled IPv6 carries it around filtering and monitoring that do not understand it.
C) IPv6 addresses are too long for most log formats
= Current logging tools record IPv6 addresses without difficulty.
D) IPv6 traffic is incompatible with TLS
= IPv6 supports IPsec and TLS like IPv4.
>> Disable or inspect unneeded IPv6 tunneling; unmanaged IPv6 can bypass IPv4-only controls.

## D4-008 | 4.1 | 2
Q: Which IPsec protocol provides confidentiality for the data it protects?
A) Authentication Header (AH)
= AH provides integrity and authentication only; it does not encrypt.
B) Internet Key Exchange (IKE)
= IKE negotiates security associations and keys; it does not protect the data itself.
C)* Encapsulating Security Payload (ESP)
= Correct. ESP encrypts the payload and can also provide integrity and authentication.
D) Security Parameter Index (SPI)
= The SPI is an identifier for a security association, not a protocol.
>> IPsec: AH = integrity and authentication (no encryption, breaks with NAT); ESP = encryption plus integrity; IKE = key negotiation.

## D4-009 | 4.1 | 2
Q: Two offices connect their networks through a site-to-site VPN between their gateways. Which IPsec mode is used?
A) Transport mode, which protects only the payload between end hosts
= Transport mode suits host-to-host protection, leaving the original IP header visible.
B)* Tunnel mode, which encapsulates the entire original packet
= Correct. Gateways wrap each whole packet in a new one, hiding internal addresses as traffic crosses the internet.
C) Aggressive mode, which speeds up key exchange
= Aggressive mode is an IKE phase 1 option, not an IPsec protection mode.
D) Main mode, which hides identities during negotiation
= Main mode is also an IKE phase 1 option.
>> IPsec tunnel mode: gateway-to-gateway VPNs. Transport mode: end host to end host.

## D4-010 | 4.1 | 3
Q: A network team wants IPsec integrity protection that covers the IP header, but the traffic crosses a NAT device. Why does Authentication Header (AH) fail here?
A) AH runs over TCP, which NAT devices handle poorly
= AH is its own IP protocol and does not depend on TCP or UDP.
B) NAT devices drop encrypted traffic by default
= AH does not encrypt anything.
C) AH was designed for IPv6 and fails on IPv4
= AH works with both IPv4 and IPv6.
D)* NAT's address changes break AH's integrity check
= Correct. AH authenticates parts of the IP header, so NAT's address changes make the check fail. ESP with NAT traversal is used instead.
>> AH and NAT are incompatible; use ESP with NAT traversal (UDP 4500).

## D4-012 | 4.1 | 2
Q: What does TLS 1.3 require that earlier versions allowed you to skip?
A) Client certificates for every connection
= Client certificates remain optional.
B)* Forward secrecy through ephemeral key exchange
= Correct. TLS 1.3 removed static RSA key exchange, so every session uses ephemeral Diffie-Hellman and a stolen server key cannot decrypt past traffic.
C) Pre-shared keys configured on both sides
= Pre-shared keys are optional in TLS 1.3.
D) Using SHA-1 for signatures
= TLS 1.3 removed SHA-1 from signatures.
>> TLS 1.3: forward secrecy mandatory, legacy ciphers removed, faster handshake.

## D4-013 | 4.1 | 3
Q: An industrial protocol carries control commands inside ordinary TCP/IP traffic, and an attacker uses that wrapping to slip commands past a firewall that only checks ports. What does this illustrate?

B) A failure of the firewall's stateful connection tracking
= State tracking worked as designed; the firewall only looked at ports, so it never saw what the wrapped payload carried.

## D4-016 | 4.1 | 2

## D4-017 | 4.1 | 2
Q: A switch begins forwarding a frame as soon as it reads the destination MAC address, before the whole frame arrives. What is the trade-off of this cut-through approach?
A) It is slower but checks every frame for errors
= That describes store-and-forward switching.
B) It drops broadcast frames to save time
= Switching method does not affect broadcast handling.

## D4-023 | 4.1 | 2
