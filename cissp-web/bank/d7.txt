# Domain 7: Security Operations (13% of the exam)

## D7-001 | 7.1 | 1
Q: A server's hard drive is seized and presented in court as evidence. What type of evidence is the drive itself?
A)* Real evidence
= Correct. Real (object) evidence is a physical item brought into court.
B) Testimonial evidence from the server administrator
= Testimonial evidence is what a witness says, orally or in writing.
C) Demonstrative evidence, such as a diagram of the network
= Demonstrative evidence helps explain other evidence, such as charts and diagrams.
D) Documentary evidence, such as printed log reports
= Documentary evidence is written material, including printouts, brought in to prove a fact.
>> Evidence types: real (objects), documentary (writings and records), testimonial (witnesses), demonstrative (aids that explain).

## D7-002 | 7.1 | 2
Q: Which rule says that when a document is introduced as evidence, the original must be used unless a valid exception applies?
A) The parol evidence rule, which governs written agreements
= The parol evidence rule says a written agreement is assumed to contain all its terms; oral side agreements cannot change it.
B)* The best evidence rule
= Correct. The original document is preferred over copies or descriptions of it.
C) The hearsay rule, which limits second-hand statements
= Hearsay concerns statements made outside court by someone not testifying.
D) The exclusionary rule for illegally obtained evidence
= That rule excludes evidence obtained in violation of rights.
>> Best evidence: originals preferred. Parol evidence: written contracts stand alone. Hearsay: second-hand statements are limited.

## D7-003 | 7.1 | 2
Q: Responders arrive at a running server that is suspected of compromise. According to the order of volatility, which data should they collect FIRST?
A) The contents of the hard disk
= Disk data persists after power-off, so it can wait.
B) Archived backup tapes stored offsite
= Archives are the least volatile source.
C)* The contents of memory (RAM)
= Correct. Registers, cache and memory disappear when the system is powered off, so they are captured first.
D) The physical network topology diagrams
= Topology changes slowly and can be documented later.
>> Order of volatility (RFC 3227): registers and cache → memory, routing and process tables → temporary files → disk → remote logs → archives.

## D7-004 | 7.1 | 2
Q: How should an investigator create a forensic copy of a seized hard drive?
A) Copy the files with the operating system's file manager
= File copies miss deleted data and slack space and change timestamps.
B) Boot the suspect system and run a backup to an external drive
= Booting the suspect system alters evidence.
C) Take a photo of the drive label and keep the original in a drawer
= That preserves nothing about the contents.
D)* Make a bit-for-bit image through a write blocker and hash both copies
= Correct. A write blocker prevents changes to the original, and matching hashes prove the image is identical.
>> Forensic imaging: write blocker, bit-stream copy, hashes of original and image, analysis on the copy only.

## D7-005 | 7.1 | 1
Q: What is the PRIMARY purpose of the chain of custody?
A)* To prove evidence integrity from collection to court
= Correct. It shows the evidence was controlled and unaltered by recording who handled it, when, where and why.
B) To list the investigators who are qualified to testify
= Qualifications matter, but they are not what the chain of custody records.
C) To speed up the processing of evidence in the lab
= Documentation adds steps; its purpose is integrity, not speed.
D) To determine which law enforcement agency has jurisdiction
= Jurisdiction is decided separately.
>> Chain of custody documents every transfer of evidence so its integrity can be proven.

## D7-006 | 7.1 | 2
Q: A smartphone seized as evidence is still powered on. What should the investigator do to preserve it?
A) Power it off immediately to save the battery
= Powering off may lose volatile data and can trigger encryption that locks the device.
B) Browse its messages to decide whether it is relevant
= Browsing changes data and may break evidence integrity.
C)* Isolate it from networks, for example in a Faraday bag
= Correct. Isolation prevents remote wiping or new data arriving, while keeping the device's state.
D) Reset it to factory settings so it can be examined safely

## D7-008 | 7.2 | 2
Q: Logs from firewalls, servers and applications are collected in one place and analyzed together to spot attacks that no single source would reveal. Which system does this?
A)* A SIEM
= Correct. A security information and event management system aggregates, normalizes and correlates events, then alerts.
B) An intrusion prevention system on the perimeter
= An IPS inspects traffic at one point; it does not correlate logs from many systems.
C) A data loss prevention agent on each endpoint
= DLP watches sensitive data, not event correlation across sources.
D) A configuration management database
= A CMDB records assets and their configurations.
>> SIEM: centralize, normalize, correlate and alert; SOAR then automates the response.

## D7-009 | 7.2 | 2
Q: Investigators cannot reconstruct the order of an attack because each server's log timestamps disagree by several minutes. Which control would have prevented this?
A) Larger log storage capacity on each server
= Storage size does not affect timestamp accuracy.
B) Encrypting logs in transit
= Encryption protects confidentiality, not time accuracy.
C) Logging more event types
= More events do not fix clock differences.
D)* Synchronized clocks (NTP)
= Correct. Synchronizing every clock to a common time source is essential to correlate events across systems.
>> Synchronize clocks (NTP) so logs can be correlated and stand up as evidence.

## D7-010 | 7.2 | 2
Q: How should an organization protect the integrity of its security logs against an attacker who gains administrator access to a server?
A) Store the logs on the same server in a hidden folder
= An administrator on that server can still find and change them.
B)* Forward them in real time to a separate log store
= Correct. Centralized, access-restricted, write-protected logging keeps evidence out of reach of an attacker on the source system.
C) Delete logs older than a day to reduce what can be altered
= Short retention destroys evidence.
D) Make the log files read-only for administrators on the server
= Administrators can change permissions back.
>> Protect logs: forward off-host promptly, restrict access, use write-once storage or hashing, and retain per policy.
