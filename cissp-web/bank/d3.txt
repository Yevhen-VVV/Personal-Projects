# Domain 3: Security Architecture and Engineering (13% of the exam)

## D3-001 | 3.1 | 2
Q: A web application's database account has full owner rights on the database, although the application only ever reads the product catalog. Which design principle does this violate?
A)* Least privilege
= Correct. The account should have only the rights it needs, here read access to the catalog. Excess rights turn an application flaw such as SQL injection into a much bigger breach.
B) Defense in depth
= Defense in depth is about layering controls; the problem here is the size of one account's rights.
C) Separation of duties
= Separation of duties splits a sensitive task between people so no one can complete it alone.
D) Fail securely
= Failing securely concerns how a system behaves when something breaks.
>> Least privilege applies to service accounts and applications as much as to people.

## D3-002 | 3.1 | 2
Q: A VPN gateway authenticates users against a central directory. What should the gateway do when the directory becomes unreachable?
A)* Deny new connections until the directory is reachable again
= Correct. Failing secure (closed) means a failure of the control does not become a way around it.
B) Allow connections from users who connected in the last 24 hours
= Cached trust may let in an account that has since been disabled.
C) Allow all connections and log them for later review
= Failing open turns an outage, or an attack on the directory, into open access.
D) Fall back to a shared emergency password published to staff
= A shared password destroys accountability and is easily leaked.
>> Fail securely: when a security control fails, it should deny rather than permit, unless life safety requires otherwise.

## D3-003 | 3.1 | 2
Q: An office uses electronically locked doors. How should the locks behave when power fails?
A) All doors should fail secure, staying locked, to protect equipment
= Locking stairwell and exit doors in an emergency can trap people.
B) All doors should fail safe, unlocking, so no one is ever trapped
= Unlocking server rooms and cages on every power cut exposes critical assets unnecessarily.
C)* Exit and stairwell doors fail safe; server cage doors fail secure
= Correct. Life safety comes first on egress routes, while doors that protect assets and are not escape routes can stay locked.
D) Doors should keep their current state until a guard decides
= In an emergency there may be no time for a decision, and egress must be guaranteed.
>> Fail-safe protects people (unlock); fail-secure protects assets (lock). Life safety always wins on escape routes.

B) Open design
= Open design means security should not depend on the design being secret.
